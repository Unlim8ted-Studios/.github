# About Unlim8ted Studios

**Unlim8ted Studios** is a dynamic entertainment production company based in the United States, founded in 2019 by an anonymous English programmer. Our mission is to create engaging and innovative gaming experiences for players around the world.

## A game we are currently working on:

### TimeCat
* **Genre:** 2D Puzzle Platformer  
* **Description:** In *TimeCat*, players control a curious cat who discovers an abandoned underground laboratory. Using a mysterious device, the cat can travel between the lab’s pristine past and its decayed present to solve cause-and-effect puzzles. By manipulating objects through time and navigating tight platforming challenges, the cat uncovers the reason the laboratory was shut down — and must solve one final puzzle to set things right before returning home.  
* **Status:** Demo already available.  
* **Planned Release:** TBD.
